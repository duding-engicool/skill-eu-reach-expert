# 合规检查清单

> 本文件为方法论/模板指引，非标准原文。涉及标准条款时以 references/01-标准原文/ 内原文为准。

## 定位与用法

用于**合规评估类任务**（SKILL.md「智能体决策逻辑」第 4 类）。执行顺序：

```
1. 读取 role-specific-guide.md  → 确认用户角色与义务边界
2. 读取 exemptions-and-waivers.md → 检查是否可豁免
3. 读取 svhc-list-cached.md / chemical-database.md → 检查物质状态
4. 读取本文件 → 逐项自查，输出缺口清单
```

**使用方式**：按用户实际角色勾选对应章节，不要四个角色全查（会引入无关义务、造成误判）。

> 本清单是**自查工具**，不是法律意见。勾选结果不构成合规证明。

## 零、通用前置检查（所有角色必做）

| # | 检查项 | 判定依据 | 结果 |
|---|--------|---------|------|
| 0.1 | 我方在供应链中的**角色**是否已明确 | 依据"谁把物质/混合物/物品投放欧盟市场"判定，见 `role-specific-guide.md` | ☐符合 ☐不符合 ☐待确认 |
| 0.2 | 涉及物质清单是否已梳理（含 CAS 号） | 每种物质必须有唯一 CAS 号，不能用别名 | ☐符合 ☐不符合 ☐待确认 |
| 0.3 | 物质的**年度吨位量级**是否已核算 | 按每个法律实体、每种物质分别核算 | ☐符合 ☐不符合 ☐待确认 |
| 0.4 | 物质形态是否已区分 | 物质本身 / 混合物中 / 物品中，三者义务不同 | ☐符合 ☐不符合 ☐待确认 |
| 0.5 | 是否已检查豁免适用性 | 见 `exemptions-and-waivers.md` | ☐符合 ☐不适用 ☐待确认 |
| 0.6 | 目标市场是否仅限欧盟 | 英国 UK REACH、土耳其 KKDIK 等为**不同体系**，义务不同 | ☐符合 ☐不适用 ☐待确认 |
| 0.7 | 知识库版本是否已核对 | 本技能知识库更新至 **2024 年**，动态信息需回官方核对，见 `cn-resources-guide.md` | ☐已核对 ☐未核对 |

## 一、制造商（Manufacturer）自查清单

| # | 检查项 | 判定要点 | 结果 |
|---|--------|---------|------|
| 1.1 | 是否已确认注册义务 | 依据年生产量级判断；< 1 吨/年通常无注册义务（须先排除豁免例外） | ☐符合 ☐不符合 ☐待确认 |
| 1.2 | 是否已取得注册号 | 注册完成后由官方下发，须留档 | ☐符合 ☐不符合 ☐不适用 |
| 1.3 | 是否已加入/参与联合提交（SIEF） | 同种物质多家企业须数据共享 | ☐符合 ☐不符合 ☐不适用 |
| 1.4 | 是否已编制并向下游提供 SDS | 危险物质/混合物须提供；格式须符合 CLP 要求 | ☐符合 ☐不符合 ☐不适用 |
| 1.5 | 是否已完成化学安全评估（CSA）并编制 CSR | 按吨位要求触发 | ☐符合 ☐不符合 ☐不适用 |
| 1.6 | 物品中 SVHC > 0.1% 且年总量超阈值时是否已通报 | 计算基数为**整件物品**；阈值要求见 `role-specific-guide.md` | ☐符合 ☐不符合 ☐不适用 |
| 1.7 | SDS 与暴露场景是否随新信息更新 | 有新增危害信息或用途变更时须更新 | ☐符合 ☐不符合 ☐待确认 |
| 1.8 | 注册信息变更是否已申报 | 吨位、用途、成分等变化须更新注册卷宗 | ☐符合 ☐不符合 ☐待确认 |

## 二、进口商（Importer）自查清单

| # | 检查项 | 判定要点 | 结果 |
|---|--------|---------|------|
| 2.1 | 是否已确认注册义务 | 进口商承担与制造商同等的注册义务 | ☐符合 ☐不符合 ☐待确认 |
| 2.2 | 年进口吨位是否已按物质分别核算 | 多种物质不合并计算 | ☐符合 ☐不符合 ☐待确认 |
| 2.3 | 境外供应商是否已指定唯一代表（OR） | 若已指定 OR，我方义务边界发生变化，须核对责任划分 | ☐已指定 ☐未指定 ☐不适用 |
| 2.4 | 是否已向境外供应商索取完整物质信息 | 含成分、CAS、吨位、用途、已有注册号 | ☐符合 ☐不符合 ☐待确认 |
| 2.5 | 是否已取得/编制中文与目的地语言的 SDS | 语言须符合目标成员国要求 | ☐符合 ☐不符合 ☐待确认 |
| 2.6 | 是否已验证供应商提供的注册号真实有效 | 不可仅凭对方口头/邮件声明 | ☐符合 ☐不符合 ☐待确认 |
| 2.7 | 物品中 SVHC 通报义务是否已履行 | 同 1.6 | ☐符合 ☐不符合 ☐不适用 |
| 2.8 | 是否已建立进口批次台账 | 用于追溯与吨位累计 | ☐符合 ☐不符合 ☐待确认 |

## 三、下游用户（Downstream User）自查清单

| # | 检查项 | 判定要点 | 结果 |
|---|--------|---------|------|
| 3.1 | 已收到的 SDS 是否为**最新版本** | 检查 SDS 版本日期，超过 3 年建议向供应商复核 | ☐符合 ☐不符合 ☐待确认 |
| 3.2 | 我方实际用途是否包含在供应商 SDS 的暴露场景中 | 不在场景内须自行做化学安全评估或通知供应商 | ☐符合 ☐不符合 ☐待确认 |
| 3.3 | 是否按 SDS 中的风险管理措施执行 | 现场操作条件须与 SDS 一致 | ☐符合 ☐不符合 ☐待确认 |
| 3.4 | 是否需要自行编制化学安全报告 | 特定情形触发，见 `role-specific-guide.md` | ☐需要 ☐不需要 ☐待确认 |
| 3.5 | 下游信息传递是否已建立 | 我方再向下游供货时同样有传递义务 | ☐符合 ☐不符合 ☐不适用 |
| 3.6 | 是否留存了供应商的合规声明 | 作为尽职免责的证据链 | ☐符合 ☐不符合 ☐待确认 |
| 3.7 | 物品中 SVHC > 0.1% 的信息传递义务是否已履行 | 供应链沟通义务（SKILL.md 中提及的 Article 33 相关要求） | ☐符合 ☐不符合 ☐不适用 |

## 四、唯一代表（Only Representative）自查清单

| # | 检查项 | 判定要点 | 结果 |
|---|--------|---------|------|
| 4.1 | 是否具备担任唯一代表的资格 | 资格要求见 `role-specific-guide.md` | ☐符合 ☐不符合 ☐待确认 |
| 4.2 | 是否已与境外制造商签署正式授权文件 | 授权书须明确覆盖的物质与责任范围 | ☐符合 ☐不符合 ☐待确认 |
| 4.3 | 是否已告知同一物质的所有进口商其 OR 身份 | 避免重复注册与责任真空 | ☐符合 ☐不符合 ☐待确认 |
| 4.4 | 是否保存了最新的进口商清单与吨位记录 | 用于吨位累计与卷宗更新 | ☐符合 ☐不符合 ☐待确认 |
| 4.5 | 注册卷宗中的非欧盟制造商信息是否完整 | 须可追溯到实际制造商 | ☐符合 ☐不符合 ☐待确认 |

## 五、合规证明文件要求

### 5.1 常见证明文档清单

| 文档类型 | 用途 | 检查要点 | 留档要求 |
|---------|------|---------|---------|
| 注册证明 / 注册号 | 证明已完成注册 | 号段格式、物质名与 CAS 号一致、持有人名称 | 长期保存，与出口记录关联 |
| 安全数据表（SDS） | 危害与风险管理信息传递 | 版本号与日期、16 个章节齐全、语言符合要求 | 现行版本 + 历史版本 |
| 化学品安全报告（CSR） | 安全评估结论 | 与注册物质对应、暴露场景完整 | 长期保存 |
| SVHC 含量声明 | 证明物品中 SVHC 含量 | 声明基准（整件物品/均质材料）、出具方、日期 | 按批次或按年度更新 |
| 第三方检测报告 | 物质含量实测 | 检测机构资质、检测方法、样品描述、报告日期 | 报告有效期需确认 |
| 符合性声明（DoC） | 自我声明符合 | 签署人、日期、覆盖的产品范围 | 与产品型号对应 |
| 授权书 / 唯一代表授权 | OR 身份与权限 | 授权范围、有效期、双方法律实体名称 | 授权期内保存 |
| 供应链沟通记录 | 信息传递义务证据 | 收件方、发送时间、内容版本 | 可追溯 |

### 5.2 文件通用校验点

- [ ] 文件上的**法律实体名称**与我方/供应商的注册名称完全一致
- [ ] 文件日期在有效期内（检测报告、声明类文件通常有更新周期）
- [ ] 覆盖的**物质/产品范围**与实际出口的一致（不能"一证通用"）
- [ ] 有出具方签章或可追溯的出具主体
- [ ] 与我方留存的批次/台账能对应上

## 六、常见违规情形对照

| # | 违规情形 | 高发原因 | 预防动作 |
|---|---------|---------|---------|
| 1 | 未注册即投放市场 | 误以为由境外供应商或买方负责 | 前置确认角色与吨位（0.1-0.7、2.1-2.2） |
| 2 | 吨位量级核算错误 | 多工厂合并/漏算、跨年度混算 | 按法律实体 + 按物质 + 按年度分别核算（0.3） |
| 3 | SVHC 计算基数用错 | 按均质材料算而非整件物品 | 明确计算口径后再判阈值（1.6） |
| 4 | SDS 版本过期 | 供应商更新后未同步 | 建立 SDS 年度复核机制（3.1） |
| 5 | 用途超出暴露场景 | 新增用途未通知供应商 | 用途变更前先比对 SDS 场景（3.2） |
| 6 | 供应链信息断链 | 只做一次声明，后续无跟踪 | 建立定期索取与复核机制（3.6） |
| 7 | 混淆清单一词 | 把候选清单当限制清单，或反之 | 先确认问的是哪一份清单（`cn-resources-guide.md` 3.4） |
| 8 | 凭别名判断物质 | 中文名/商品名歧义 | 一律以 CAS 号比对（0.2） |
| 9 | 沿用过期知识库结论 | 清单已更新但未复核 | 每次评估先做版本核对（0.7） |
| 10 | 目标市场法规混淆 | 把欧盟 REACH 结论套用到英国/土耳其等 | 先确认投放市场（0.6） |

## 七、评估输出格式

完成自查后，按以下结构输出给用户：

```
【角色认定】<角色>　依据：<判定理由>

【自查结果汇总】
- 已符合：X 项
- 不符合：X 项
- 待确认：X 项
- 不适用：X 项

【不符合项清单】
| 编号 | 检查项 | 现状 | 差距说明 | 建议动作 |
（逐项列出）

【待确认项清单】
| 编号 | 检查项 | 需要用户补充什么 |
（逐项列出）

【优先处理建议】
1. <按风险与紧迫度排序>

【版本与免责提示】
本技能知识库更新至 2024 年，动态信息请以官方最新公告为准；
本自查结果为工具性输出，不构成法律意见。
```

### 优先级判定参考

| 情形 | 优先级 | 说明 |
|------|--------|------|
| 未注册即投放市场 | 最高 | 直接影响市场准入 |
| 吨位/角色判定错误导致的义务遗漏 | 高 | 可能连带其他义务 |
| SVHC 通报义务未履行 | 高 | 有明确的时间要求 |
| SDS 版本过期 | 中 | 影响下游合规链条 |
| 文件留档不完整 | 中 | 影响追溯与举证 |
| 待确认项 | — | 列出所需信息，等用户补充后再判 |

## 八、待核实事项

| 事项 | 说明 |
|------|------|
| 具体条款号与条款原文 | 本清单**不引用任何法规条款原文**。需要条款级依据时，请查阅 `reach-overview.md` 及官方法规文本；本技能未内置 REACH 法规原文 |
| 各类阈值的具体数值 | 本清单只给出"需检查阈值"，具体数值请以 `role-specific-guide.md` 与官方文件为准 |
| 检测报告有效期 | 不同客户/机构要求不同，需用户向委托方确认 |
| 各成员国语言要求 | SDS 的语言要求因成员国而异，需按实际出口国确认 |
| 唯一代表授权书标准模板 | 本技能未提供，需用户咨询专业机构 |
| 2024 年之后的清单更新 | 本技能知识库截止 2024 年，之后新增的 SVHC 批次未收录 |
| 特定行业的叠加要求 | 电子电器、玩具、纺织、食品接触、汽车等行业另有专门法规，本清单未覆盖 |
