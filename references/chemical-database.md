## 1. 常见化学品分类

### 1.1 按用途分类

| 类别 | 常见物质 | 主要用途 | 法规关注度 |
|------|---------|---------|-----------|
| 塑化剂 | DEHP, DBP, DINP, DIDP | PVC塑料、玩具 | ⭐⭐⭐⭐⭐ |
| 阻燃剂 | TCEP, TBBPA, HBCDD | 电子产品、家具 | ⭐⭐⭐⭐ |
| 颜料/染料 | 镉系、铅系颜料 | 油漆、塑料 | ⭐⭐⭐⭐⭐ |
| 表面处理 | 铬(VI)化合物 | 电镀、防锈 | ⭐⭐⭐⭐⭐ |
| 溶剂 | 三氯乙烯、苯、甲苯 | 清洗、稀释 | ⭐⭐⭐⭐ |
| 单体/聚合物 | 苯乙烯、丙烯酸酯 | 树脂、涂料 | ⭐⭐⭐ |

### 1.2 按危害分类

**致癌物质（CMR 1类/2类）**：
- 苯
- 甲醛
- 镉及其化合物
- 铬(VI)化合物
- 砷及其化合物
- 石棉

**生殖毒性物质**：
- 邻苯二甲酸酯类（DEHP, DBP, BBP等）
- 铅及其化合物
- 汞及其化合物
- 双酚A
- 全氟辛酸（PFOA）

**持久性、生物累积性物质（PBT/vPvB）**：
- 全氟化合物（PFOA, PFOS）
- 短链氯化石蜡
- 镉化合物

## 2. 重点化学品详解

### 2.1 邻苯二甲酸二(2-乙基己基)酯 (DEHP)

**基本信息**：
| 项目 | 内容 |
|------|------|
| 中文名 | 邻苯二甲酸二(2-乙基己基)酯 |
| 英文名 | Bis(2-ethylhexyl) phthalate |
| CAS号 | 117-81-7 |
| EC号 | 204-211-0 |
| 分子式 | C24H38O4 |
| 分子量 | 390.56 g/mol |

**物理化学性质**：
| 项目 | 内容 |
|------|------|
| 外观 | 无色透明油状液体 |
| 密度 | 0.986 g/cm³ (20°C) |
| 熔点 | -50°C |
| 沸点 | 386°C |
| 闪点 | 218°C |
| 溶解性 | 不溶于水，可溶于多数有机溶剂 |

**主要用途**：
- PVC塑料增塑剂（主要用途）
- 玩具、医疗器械
- 食品包装材料
- 油漆、涂料
- 粘合剂

**健康危害**：
- 生殖毒性（已被证实）
- 内分泌干扰
- 肝脏毒性
- 可能致癌

**环境危害**：
- 难以生物降解
- 在环境中持久存在
- 生物累积性

**REACH法规状态**：
- SVHC候选物质：2008年10月加入
- 加入原因：生殖毒性（第57c条）
- 授权物质：已在授权清单中
- 日落日期：2015年2月21日

**替代物质**：
- DINP（邻苯二甲酸二异壬酯）
- DIDP（邻苯二甲酸二异癸酯）
- TOTM（偏苯三酸三辛酯）
- DOTP（对苯二甲酸二辛酯）

### 2.3 双酚A (BPA)

**物理化学性质**：

| 溶解性 | 微溶于水，可溶于乙醇、丙酮 |

**主要用途**：

- 内分泌干扰

- 禁止用于婴幼儿奶瓶（REACH限制清单）
- 热敏纸中含量限制

**替代物质**：
- 双酚F (BPF)
- 双酚S (BPS)
- 四溴双酚A (TBBPA)
