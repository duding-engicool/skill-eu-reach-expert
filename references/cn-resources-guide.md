# 国内资源使用指南

> 本文件为方法论/模板指引，非标准原文。涉及标准条款时以 references/01-标准原文/ 内原文为准。

## 定位

当本技能内置知识库（`svhc-list-cached.md`、`chemical-database.md`、`registration-guide.md`、`exemptions-and-waivers.md`、`role-specific-guide.md`）无法完全满足用户需求时，读取本文件，为用户提供**可自行进一步查询的国内资源与查询路径**。

**使用原则**（与 SKILL.md 一致）：
- 不访问欧盟网站，优先走国内可访问资源
- 提供的是**查询路径与方法**，不是结论本身
- 动态数据（SVHC 清单版本、物质状态、截止日期）必须以用户查到的**当下官方信息**为准
- 复杂个案建议咨询专业机构

## 二、分场景查询路径

| 用户要查什么 | 建议查询顺序 | 拿到结果后要核对什么 |
|-------------|-------------|---------------------|
| 某物质是否在 SVHC 清单 | ① 先查 `svhc-list-cached.md` → ② 清单版本不一致时，用 1.3 的专业服务资源或 1.1 政府/行业渠道核对最新增补批次 | 清单**更新日期**、物质的中英文名与 CAS 号是否对得上 |
| 某物质的理化性质 / CAS / EC 号 | ① `chemical-database.md` → ② 1.2 化学品数据库 | CAS 号（不同数据库可能有别名歧义，以 CAS 号为准） |
| 需要 SDS/MSDS | ① 向供应商索取最新版 SDS → ② 1.2 的 MSDS 数据库补充 | SDS 版本日期、是否为**欧盟 CLP 格式**、第 15 部分法规信息是否含 REACH |
| 某物质是否需要注册 / 能否豁免 | ① `exemptions-and-waivers.md` → ② `registration-guide.md` → ③ 仍不确定则转专业机构 | 年吨位量级、物质形态（本身 / 混合物中 / 物品中）、是否聚合物 |
| 某产品出口到欧盟要做哪些合规动作 | ① `role-specific-guide.md` 确认角色 → ② `compliance-checklist.md` 自查 → ③ 按缺口逐项查 | 自身在供应链中的**角色定位**（制造商/进口商/下游用户/唯一代表） |
| SVHC 含量是否超 0.1% | ① 拆解到均质材料层级 → ② 逐层做物质筛查 → ③ 数据不足时要求供应商提供声明或检测报告 | 计算基准是**整件物品**还是**均质材料**（这是最常见的理解错误） |

## 三、信息核验方法

### 3.1 交叉验证原则

| 步骤 | 动作 |
|------|------|
| 1 | 同一事实至少查 2 个独立来源 |
| 2 | 两个来源冲突时，**优先采信一手来源**（官方公告、法规原文） |
| 3 | 二手来源（行业解读、公众号、论坛）只用于**理解**，不用于**定性** |
| 4 | 仍冲突时，如实告知用户存在版本差异，并建议咨询专业机构 |

### 3.2 一手性判断

| 级别 | 特征 | 能否作为合规依据 |
|------|------|-----------------|
| 一手 | 法规原文、官方公告、官方物质数据库条目 | ✅ 可以 |
| 准一手 | 官方授权的中文译本、官方指南文件 | ✅ 可以，但需注明译本 |
| 二手 | 行业媒体解读、服务商文章、培训材料 | ❌ 不可单独作为依据 |
| 三手 | 论坛、问答、社交平台内容 | ❌ 仅作线索 |

### 3.3 时间戳核查

任何动态信息在引用前必须确认三项：

- [ ] 该信息的**发布/更新日期**是什么
- [ ] 本技能知识库的信息更新时间为 **2024 年**（见 SKILL.md 注意事项），是否已过期
- [ ] 用户查询当天是否有更新的批次/修订

> **强制性动作**：当用户问题涉及 SVHC 清单版本、注册截止日期、限制条款等**随时间变化**的信息时，必须提示用户"本技能知识库更新至 2024 年，请以官方最新公告为准"。

### 3.4 常见查询陷阱

| 陷阱 | 说明 | 规避方式 |
|------|------|---------|
| 名称歧义 | 同一物质有多个中文别名、商品名 | 一律以 **CAS 号**作为唯一比对键 |
| 清单版本混淆 | SVHC 候选清单、授权清单（附件 XIV）、限制清单（附件 XVII）是三份不同的清单 | 先确认用户问的是哪一份 |
| 吨位量级错判 | 按错误吨位判断注册义务 | 按**年度**、按**每个法律实体**、按**每种物质**分别核算 |
| 角色错判 | 把下游用户当成进口商 | 依据"谁把物质/物品投放到欧盟市场"判定 |
| 计算基数错 | SVHC 0.1% 的基数是整件物品而非均质材料 | 见 `role-specific-guide.md` 相关说明 |
| 译本误差 | 中文译本节选导致理解偏差 | 关键判断回原文条款核对 |

## 四、专业咨询机构的选择

本文件**不提供具体机构联系方式**（联系方式变动频繁，且不宜由技能代为背书）。提供选择标准，由用户自行接洽。

### 4.1 筛选标准

| 维度 | 考察点 |
|------|--------|
| 资质 | 是否具备相关检测/认证资质，是否为官方认可的机构 |
| REACH 专项经验 | 是否有同行业、同产品类别的实际服务案例 |
| 服务范围 | 能否覆盖：物质筛查 → 检测 → 注册/通报代理 → 供应链信息传递 |
| 信息时效 | 是否有常态化的法规跟踪与更新通知机制 |
| 交付物 | 是否提供可留存的正式报告/声明文件（合规证明需可追溯） |
| 责任边界 | 是否明确说明其意见的法律效力与免责范围 |

### 4.2 建议向机构提出的关键问题

1. 我方在供应链中属于什么角色？对应的具体义务有哪些？
2. 我方产品涉及的所有物质/材料中，哪些是目前的管控重点？
3. 需要准备哪些合规证明文件？有效期多久？
4. 我方是否需要指定欧盟境内唯一代表（OR）？
5. 后续清单更新时，是否有主动通知机制？

### 4.3 委托前自查清单

- [ ] 已明确自身供应链角色
- [ ] 已整理产品 BOM 与材料清单（到均质材料层级）
- [ ] 已收集现有供应商的合规声明与 SDS
- [ ] 已明确目标市场与年出口量级
- [ ] 已确认本次服务的范围与交付物清单（写入合同）

## 五、待核实事项

以下内容**本文件未提供**，需由用户核实或补充：

| 事项 | 说明 |
|------|------|
| 网址有效性 | 第 1 节所有网址可能变更，使用前需验证 |
| 具体栏目路径 | 各网站内部的具体查询入口、检索方式需用户自行摸索或咨询站方 |
| 机构联系方式 | 电话、邮箱、地址等一律不收录，需用户通过官方渠道获取 |
| 付费服务价格 | 各服务商收费标准差异大，需用户直接询价 |
| 2024 年之后的法规更新 | 本技能知识库截止 2024 年，之后的 SVHC 增补批次、法规修订均**未收录** |
| 特定行业的专门要求 | 电子电器、玩具、纺织、汽车等行业另有专门法规（如 RoHS、玩具安全指令等），本技能未覆盖，需另行查询 |
| 官方中文译本目录 | REACH 相关指南的官方中文译本清单，需由用户提供或核实 |
